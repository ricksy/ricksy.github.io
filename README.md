# ricksy.github.io

A redirect. The site is at **<https://mufradat.com>**, built from
[ricksy/mufradat](https://github.com/ricksy/mufradat) and published by GitHub
Pages from that repository.

This repository used to hold an unfinished Hugo scaffold from 2021 — "My New
Hugo Site", one post called `my-first-post`. It is still in the history if it
is ever wanted; `git log` before this commit.

It also used to claim `mufradat.com` as its custom domain, which is why the
real blog was initially assigned `mufradat.com/mufradat/`. A domain can be
claimed by only one repository, so that claim was released. **Do not add a
CNAME file here** — a Pages build would try to take the domain back from the
repository actually serving it.
